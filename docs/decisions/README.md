# Project decisions (ADRs)

Decisions with lasting effect for VOJAĜO — architecture, technology, data format,
security, UX patterns, project-wide exceptions to the standards — are recorded here as
one file each: `ADR-NNN-short-title.md`.

- Template: `adr-template.md` in the central engineering standards (`templates/`).
- A new ADR starts with status `Proposed`. Only the project owner sets `Accepted`.
- An accepted ADR is never edited in substance; a change is a new ADR that supersedes it.
- Cross-project decisions live in the central standards repository and are cited as
  `ES-ADR-NNN`; they are not copied here.
